# Tools

Interactive utilities: teaching tools and personal pages that are not mathematical visualizations. Served with GitHub Pages.

Site: <https://antoniojpan.github.io/tools/>

Each page is a self-contained HTML file; dependencies load from CDNs. `index.html` is only a catalogue, every tool has its own stable URL.

## Contents

|---|---|

## Migration from `ajpancollantes.github.io/cajondes/`

Originally published inside the `ajpancollantes/ajpancollantes.github.io` repository. Mapping is one to one:

```
ajpancollantes.github.io/cajondes/<name>.html  ->  antoniojpan.github.io/tools/<name>.html
```

The mathematical visualizations that lived in the same folder were moved to <https://github.com/antoniojpan/visualizations>. The old copies are still online; nothing was deleted.
