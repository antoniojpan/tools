Compilador estricto: distingue mayúsculas de minúsculas, exige llaves { } balanceadas y tipos exactos en cada parámetro.

1. Estructura

Todo programa necesita una rutina principal. Las subrutinas se declaran antes.

tempo 120

rutina BajoBase {
    tocar nota bajo(C2, 1)
}

rutina principal {
    llamar BajoBase
}

2. Control de flujo

  • repetir N veces { ... } Crea la variable vuelta (1 a N).
  • si A == B entonces { ... } sino { ... } Comparadores: == != < > <= >=. sino es opcional.
  • juntos(Rutina1, Rutina2) Ejecuta las rutinas en paralelo y espera a que terminen.

3. Instrucciones

  • tocar nota instrumento(Nota, duracion) Instrumentos: guitarra piano bajo sinte. Notas C1..B6 (C3, F#2, Bb4).
  • tocar acorde instrumento(Acorde, duracion) Raíz A..G con #/b y sufijo opcional: m 7 m7 maj7 sus4 dim. Ej: Am, F#m.
  • tocar bateria(pieza, duracion) Piezas: bombo caja platillo charles.
  • esperar(duracion) · azar(min, max) Pausa N pulsos / entero aleatorio entre min y max.

4. Palabras clave

  • tempo N Pulsos por minuto. Entero de 30 a 300.
  • rutina Nombre { } Declara una subrutina. No puede coincidir con una palabra clave, ni siquiera con mayúscula inicial (Bateria no es válido).
  • rutina principal { } Punto de entrada obligatorio y único.
  • llamar Nombre Llama a otra rutina y espera a que termine.
  • juntos(A, B, …) Lanza dos o más rutinas en paralelo.
  • repetir N veces { } Bucle contado. Dentro existe vuelta (1 a N, solo lectura).
  • si … entonces { } sino { } Condicional. sino es opcional.
  • tocar nota instrumento(Nota, dur) Una nota.
  • tocar acorde instrumento(Acorde, dur) Un acorde.
  • tocar bateria(pieza, dur) Percusión.
  • esperar(N) Silencio de N pulsos.
  • azar(min, max) Entero aleatorio entre min y max.
